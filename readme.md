## ⭐星归之约定⭐

本作品由Godot4.5引擎进行开发，可在Windows PC端运行。



　星之国王女结月被摄政王携月设计陷害，坠落到陌生星球，她要带着史莱姆飞回去，见到未婚妻。故事的终点是两人的婚礼。有了这个明确的目的，向上飞行、穿过宇宙和接近王城，就都有了理由。

　在玩法构思上，最早的想法是躲陨石、挥剑和冲刺，但是考虑到宇宙背景，自然想到了可以引入类似引力的机制。玩家可以通过引力改变弹幕的速度和方向，把危险引走，把陨石转成星屑，获得强化，再找机会靠近敌人。看似陨石是危险，实则是必要的宝藏。

　为了增强操作感， 设计蓄力机制，让蓄力后攻击范围和伤害一起增加；冲刺靠冷却限制，按住时减速瞄准，松开后突进并清除沿途弹幕。慢速移动帮助玩家穿过细小空隙，史莱姆则提供回血、回魔、护盾或攻击援助。星屑要亲自拾取，升级也在战斗中完成，玩家需要自己找安全的时机。
　
　最后游戏中有不同的收藏品，需要玩家完成各样的挑战。
